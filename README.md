# Salvage-Burn-Flex

Let people mint NFTs on Monad that prove they burned tokens on other chains, and later also index abandoned/burned assets.

## 1. Vision

Massive amounts of crypto have been **burned or effectively abandoned**:
- Sent to dead addresses like `0x0000…0000`
- Stuck forever in lost-key wallets
- Publicly known cases (presale mistakes, protest burns, lost EOAs)

The value is gone on the base layer.

But the **stories, sacrifices and “dead” liquidity** can still be **salvaged**.

**Salvage Burn Flex** is a cross-chain protocol (with NFTs on **Monad**) that:

1. Turns real burns into **Salvage Burn Credits (SBC)** – bragging-right NFTs.
2. Lets **Salvagers** claim discovery rights on unclaimed burns.
3. Builds an **overlay layer** for burned and “abandoned” assets, using:
    - proof-of-burn,
    - proof-of-abandonment heuristics,
    - smart contracts + governance,
    - and an optional public-goods treasury.
